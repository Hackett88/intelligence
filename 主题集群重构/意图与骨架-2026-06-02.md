# 主题集群重构 · 意图与骨架

## 初衷（Sean 原话提炼）
当前选题工作台的 sub-pillar / Cluster page 关系**不符合**标准模型（`SEO文章中的关键词的若干疑问.md` 的 Topic Clusters + GEO 黄金公式）。
要：**做一个可多次复用的 workflow**，吃关键词进料，结合 创意/搜索/写作 Agent + blog/seo-geo plugin + 标准模型，
**重新设计 sub-pillar 标题、Cluster page 标题，及每页的 主标题/副标题/主关键词/次关键词词群/GEO概述**，
形成完整主题体系并**成功绑定到页面**（可先解绑现有重绑）。

## 标准模型要点（参照文件）
- **Topic Cluster**：1 支柱 + N 卫星页；每个卫星页**只打一个意图**（信息/交易/比较/技术长尾）；卫星↔支柱内链。
- **决策表**：高量高竞→支柱；长尾低竞→精准问答；语义相近→并页；对比评价→漏斗页。
- **GEO 黄金公式**：每页 30–60 字直接答案摘要(GEO概述) + 信息增益 + 实体/Schema + 引用权威 + FAQ 对话式意图。

## Sean 已拍板的三个岔路
1. **字段落库** = 扩 schema 加列（`strategy_pages`.subtitle / geo_overview）。次词群=该页绑定的真实词；实体词沿用 aux_keywords。
2. **层级** = 每个**列=一个大主题**；每个格子 = **1 个 sub-pillar（格子大标题，实体支柱页）+ 数个单意图 Cluster pages**；删空壳"中枢"。
3. **产出深度** = 只出主题体系蓝图（标题/副标题/主次词/GEO概述 + 绑定），不写正文（正文留给后续 blog-cluster）。
