# 执行日志 · Dhikr 填充 M3(抽屉) + M4(亮绿)

## 服务的上层目标
骨架 v2 的 M3 + M4。打通「计划词 vs 收录索引实际词」对照、URL 命中收录索引自动亮绿+引数据、命中 URL 清单与跳转。

## 数据通道（共用）
- `_workbench.ts`：新增类型 `IndexedQueryRow / IndexedUrlMatch / IndexedMatches`；纯函数 `toBasePath / matchIndexed / effectiveStatus`（客户端可用，与 _gsc-rankings basePath 同源）。
- `_gsc-rankings.ts`：新增 `getIndexedMatches()` —— 按 basePath 聚合所有 locale/market 变体（pageId/fullUrl/market/position/clicks/impressions/indexState + 每变体 top15 queries），收录口径 position>0。
- `page.tsx`：并行 `getMarketRankings() + getIndexedMatches()`，经 WorkbenchWrapper → WorkbenchClient → LoomGrid + InspectorPanel 透传。

## M4 亮绿（LoomGrid + InspectorPanel）
- `effectiveStatus(url, ownStatus, idx)`：URL 命中收录索引任一变体 → live，否则用页面自身 status。
- LoomGrid：cells 的 sub-pillar/cluster 状态点、行头 pillar 状态点全改走 effectiveStatus（useMemo 依赖加 indexedMatches）。
- InspectorPanel：状态 chip 用 effStatus + 「收录命中」小标记；新增「收录索引命中」区——列出命中的全部变体 URL（旗+basePath+#排名+点击）+ 数量 + 点击跳 `/app/indexing?focus=<pageId>`。
- `IndexingClient.tsx`：mount 读 `?focus=<pageId>` → setSelectedId + 打开抽屉（deep-link）。

## M3 抽屉关键词标签页（InspectorPanel）
- 关键词区由「并排」改为「计划词 / 实际词」标签页切换。
- 计划词 Tab：绑定词（dedup），命中（∈实际查询词）→ 绿色 + 「命中」标记。
- 实际词 Tab：`aggregateQueries(matches)` 聚合多变体查询词（同词合并、clicks/impressions 累加、position 按曝光加权），被规划（∈计划词）→ 绿色 + 「已规划」。
- 辅助词[实体]：从 page.note 解析展示（只读，弱样式 chip）。「可改删」(M3c)留待 M6。
