# GA4 保留字段设计逻辑（收录与索引 · 单 URL 抽屉）

## 0. 这张卡是干什么的

「收录与索引」模块 = 从 Google Search Console 抓每个 URL 的搜索收录与表现。点一个 URL → 右侧抽屉 = 这个页面的「体检卡」。

一条完整的用户路径被拆成两半：

- **进站前（GSC）**：曝光 → 排名 → 点击 → CTR —— "用户怎么找到这页的"
- **进站后（GA4）**：进来之后做了什么 —— GSC 永远答不了的另一半

GA4 这半部分的取舍，经过五个视角并行评审（SEO 决策 / GA4 口径 / 信息架构 / 行业最佳实践 / 现实校验）后定稿。本文记录**为什么最终只留这几个字段**。

## 1. 取舍的总原则：一个字段要三关全过才留

一个 page-level 指标要配活在这张单 URL 卡上，必须同时满足：

1. **可比性** —— 单看一页的这个数，不依赖"该页类型的基准"，就能读出意义。读不出（被内容长短/功能扭曲）→ 它只能当"同页历史趋势"用，不能当孤立裸值摆。
2. **不冗余** —— 它讲出了 GSC 或别的保留指标没讲的事。
3. **可行动** —— 它的"好/坏"会改变一个 SEO 决策。

## 2. 保留的 4 个字段 + 各自的逻辑

### 2.1 互动率 Engagement Rate —— 唯一带"好/坏"判断的 hero

- **是什么**：互动会话 ÷ 总会话。一个会话满足"停留>10秒 / 翻≥2页 / 触发≥1次关键事件"任一条即算"互动会话"。≈ 1 − 跳出率（GA4 已把 bounce rate 重定义为 1−engagement rate）。这是 GA4 唯一官方口径，没有第二种标准算法。
- **为什么是 hero**：它的门槛是**低位绝对阈值**，不随内容长短线性漂移（200字FAQ只要有人读15秒/点第二页就算"互动"）。所以它跨页面类型**可比**，是唯一敢打绝对分档色的 GA4 指标。
- **回答什么决策**："GSC 把人带进来了，这页到底接没接住？"低互动率 = 落地即走 = 意图错配或落地体验差 → 是"该不该继续给这页投 SEO 力气"的判断信号。
- **阈值（已校准）**：**≥60% 良好 / 45–60% 一般 / <45% 偏低**。
  - 依据：Databox 真实账户聚合，全行业中位 ~56%、电商 ~64%（见 research-ga4-engagement-rate-standard-2026-05-27.md）。
  - 初版误设 55/35 偏松（绿灯≈及格线、红线过松），已上调。
  - 站点是电商+大量长篇内容混合，故取"通用偏严"的 60/45，未用纯电商 65/50。
  - **长期**：接真实数据后改为"按页面类型自校准"（商品页可收紧到 65/50，内容页另算）。

### 2.2 活跃用户 Active Users —— 中性底数，不做头牌

- **是什么**：与网站发生互动的去重用户数（GA4 默认"用户"即活跃用户）。
- **为什么不当主角**：① 它和 GSC 点击讲的是同一件事（都≈进站量），冗余；② 它是**全渠道**的（实测全站 Direct 1336 > Organic 1038，自然搜索仅四成），不等于"SEO 带来的人"。
- **为什么仍留**：它是互动率、（未来）转化率等比率的**分母**，没它那些率算不出来。
- **口径标注**：必须标"全渠道去重 · 非纯自然搜索"，防止被误读成 SEO 流量。

### 2.3 平均互动时长 Avg Engagement Time —— 保留但不打分

- **是什么**：每次会话平均互动时长（**per session**，不是 per active user）。
  - 口径修正：单页体检问的是"每次访问待多久"，该用 per session；per active user 按人头摊、受回访扭曲、跨页不可比。初版用错，已改正。
- **为什么不打好坏色**：内容长短决定时长——实测同批高流量页从 12秒（列表页）到 43秒（长文）摆 3.5 倍。一篇长文 50 秒可能没读完，一个工具页 50 秒已很投入。**任何统一秒数阈值都是错的**，所以只展示裸值 + 标"对照同类型页基准"。
- **基准方法论（待真实数据后建）**：三层叠加 —
  1. 主判定：本站**同页面类型**的分位数（P25/P50/P75），告诉你"高于同类页中位 +X%"；
  2. 内容页加成：read-time 完成比（按字数估应读时长，看实际读了百分之多少）；
  3. 全页通用：历史趋势箭头（跌 >20% = 内容衰退预警）。
  - 硬依赖：必须先用真实 GA4 数据跑"各页面类型 × 各语言"的分布、确认样本量，才能建分位数基准。详见 research-ga4-engagement-time-baseline-2026-05-27.md。

### 2.4 站点语言 × 来源国 —— 不是裸国家榜，是 hreflang 诊断

- **是什么**：这页是哪个语言版（站点语言）+ GA4 实际来源国 Top N，两者对不对得上。
- **为什么这么设计**：裸国家榜对单页 SEO 无指引（"来自沙特/埃及"so what）。有价值的是**交叉**：语言版页面（/ar /fr /de /tr）若主力来源国说的是另一种语言 → 多半 hreflang 配错 / 国际化失血（流量被引到了错的语言版，来了也看不懂）。
- **判定**：
  - 英语默认站 → 全球流量属正常，不评判（中性）。
  - 语言版页 → 主力来源国在该语言的预期国家池内 = "语言一致"（绿）；不在 = "疑似 hreflang 不一致"（橙告警），且该来源国行高亮。
- **实现注意**：一致性用"是否属于站点语言的国家池"判断（池membership），不用全局 country→language 单值映射——因为一国可属多语族（摩洛哥=阿/法、瑞士=德/法），单值映射会误判。

## 3. 被裁掉的，以及为什么

| 裁掉 | 原因 |
|---|---|
| 浏览次数 / 每用户浏览量 | 与活跃用户/点击高度共线，冗余 |
| 事件数 | page_view+scroll+click 混在一起，语义不纯、不可行动 |
| 新用户 / 会话 | 与活跃用户共线，对单内容页 SEO 动作无影响 |
| 关键事件数 / 转化率 | 实测前 10 高流量页关键事件全为 0（在结账页触发，不在内容/商品落地页），对 SEO 页面恒零 |
| 购买次数 / 收入 | 全站购买率 ~0.4%、单页≈0；且为会话级着陆归因（非本页成交），放收录卡会被误读成"这篇文章卖了X元"。归 FRUCTUS「表现与迭代」模块 |
| 跨数据源漏斗（曝光→点击→活跃用户→购买 + 段间相除转化率） | 三段三套口径（GSC仅自然搜索/90天 vs GA4全渠道/28天 vs 购买≈0），相除是伪精确 |

## 4. 一句话立场

GA4 在这张收录卡里，从"塞一堆数字"收敛成 **一个真信号（互动率）+ 一个底数（活跃用户）+ 一个待建基准的补充（互动时长）+ 一个诊断告警（语言×来源国）**。

判这页 SEO 好坏的转折点是**互动率**——它判的是"你引来的流量是不是对的人 / 这页接不接得住"。其余要么是它的铺垫，要么是做判断的背景。

## 5. 待办（都卡在同一件事上）

1. **真实 GA4 数据接入**（GA4 Data API / 浏览器抓取；按 landing page + organic 渠道收窄口径；时间窗对齐到 28d；schema 存储）——这是总卡口。接通后解锁：
2. 互动时长「同页面类型分位数」基准；
3. 互动率「按页面类型自校准」阈值；
4. 纯 GSC 的「排名好(≤10)但 CTR 低于位次基准」告警（不依赖 GA4，性价比最高，应先上）。
