# Stage 2 · 方案骨架与详设（待 Sean 拍板）

团队产出：Plan（实现架构 + 分层 todo）+ Sparko（口径决断）+ 早前 researcher（采集方法）。本文是收口。

## 一、架构骨架（一句话）

GA4 数据**在同一次 sync、同一个 CDP 连接里**顺带拉取（内部 venus 接口，零凭证），按 `classifyCadence` 与 GSC **同档**，按 **pathname** 对齐写进**同一行 `gsc_pages`**（扩 5 列），loader 映射进 `PageRow.ga4`，抽屉自动从 mock 切真实。GA4 失败**不拖垮 GSC**（独立 try/catch 降级）。

```
一次 sync（本地浏览器）
  ├─ 抓 GSC 页面级 4 指标 + 逐页关键词   （现有，不动）
  ├─ 【新】同 CDP 连接 POST venus 拉 GA4：
  │     · 指标查询: landing_page × [active_users, engaged_sessions, sessions, user_engagement_duration]
  │     · 国家查询: [landing_page, country] × active_users → 按 page 分组取 Top10
  │     · 派生 engagementRate / avgEngagementTime；读采样标志
  │     · 范围 = 与 GSC 同一个 pagesToQuery（日/周/月同档）
  ├─ 按 pathname 合并进同一批 realRows（GA4 失败则留 NULL，不阻断）
  └─ saveBatch（gsc_pages 同行存 GSC+GA4）+ JSON 兜底
        → loader 映射 ga4 列 → PageRow.ga4 → 抽屉读真实（已就绪，几乎零改）
```

## 二、关键设计决策（来自 Plan，已审，采纳）

1. **schema：gsc_pages 加 5 列**（全 NULLable 无默认 → 对存量行零影响、向后兼容）：
   `ga4_active_users INT` / `ga4_engagement_rate DOUBLE` / `ga4_avg_engagement_time DOUBLE` / `ga4_top_countries JSONB` / `ga4_sampled BOOL`。**NULL = 没拉到/无数据**（前端回退 mock+待接入标），区别于真实 0。
2. **手写 migration `0010_ga4_columns.sql`**（`ADD COLUMN IF NOT EXISTS`，延续 0009 手写习惯，**不跑 drizzle push**）；回滚 = `DROP COLUMN IF EXISTS` ×5（在线 DDL，加 NULLable 列不重写表，无损存量）。
3. **抽出 `src/lib/gsc/cdp.ts`**：把 `connectBrowser/resolveBrowserWSEndpoint/chromeUserDataDir` 从 fetcher.ts 移出共享（严禁复制粘贴致漂移）。纯重构，用现有 GSC sync 回归验证。
4. **新建 `src/lib/gsc/ga4-fetcher.ts`**：venus 双查询封装 + 分页(offset 循环) + 派生 + Top10 分组 + 采样读取 + 重试1次 + 不抛（失败返回空+failed 标志）。property/dataset 走**环境变量**（`GA4_PROPERTY_ID`/`GA4_DATASET`），不硬编码。
5. **sync 集成点**：saveBatch 之前插入；范围 = `pagesToQuery.map(p=>p.url)`（同档）；carry 带上一批 GA4（增量档未爬页不被清空）；JSON 兜底回填 `.ga4`。
6. **loader 唯一映射点** `rebuildPagesFromReal`：GA4 列 → `PageRow.ga4`（全空则 undefined → 前端回退）。**前端 `DetailDrawer` 第 789-792 行 `page.ga4 ?? mock` 已就绪，几乎零改**。
7. **mock 清理（Stage 7）**：删 `mockGa4ForPage`；**保留** `GA4_COUNTRY_BY_LANG`/`ga4CountryPoolKey`（被 LangGeoConsistency 真实 hreflang 诊断依赖，非 mock），建议迁出 `_mock.ts` 防误删。

## 五、风险与回滚（要点）

- 生产迁移 → `DROP COLUMN` 回滚，NULLable 加列无损存量。
- venus 是无契约内部接口 → fetcher 结构校验 + failed 降级 + GSC 不受影响 + 抽屉回退 mock。
- **path 对齐是真正暗雷**（多语言尾斜杠/大小写/query）→ Stage 4 抽查对齐命中率，fetcher 内尾斜杠归一对齐 GSC splitUrl，失配页留 NULL 不报错。
- GA4 拉取失败/异常全程不 rethrow，GSC 主流程不受影响。
