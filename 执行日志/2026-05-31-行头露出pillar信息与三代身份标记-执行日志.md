# 执行日志 · 行头露出 pillar 信息 + 三代身份标记

## 缘起（Sean 提问）
"为什么我没有在表中看到 Pillar Page 的信息？" —— 行=品类，每行背后有张 pillar 页，但行头只画了静态品类名(en/zh)，没拉 pillar 页的状态/SV/身份。形成不对称：爸爸(sub-pillar)在格子里以"页"露面，爷爷(pillar)却被压成光秃秃的名字。Sean 指示：确保 pillar 信息显示、三代都能看到、且辨别得出所属关系。

## 改动（仅 LoomGrid.tsx overview）
1. **行头露出 pillar**（~L631-665）：取 `catPillar = pagesByTheme.get(cat.id).find(role pillar)`；子树 SV = 该 theme 下所有页绑定词 SV 之和。行头排成：◆`RoleMark pillar` + 英文名 / 中文名 / `StatusDot(pillar.status)` + `formatSv(子树SV)`（为 0 不显示；无 pillar 显示 "no pillar"）。保留 grip 拖拽、点击进整树下钻。
2. **格子爸爸带标记**（~L678）：每个 sub-pillar 条目 `StatusDot + ◈RoleMark sub-pillar + 标题`（身份与状态并存）。

## 辨别所属关系的机制
- **身份标记**：◆pillar（实心菱形）/ ◈sub-pillar（镂空菱形）/ ○cluster（圆点），三代一眼分开。
- **位置**：某行格子里的爸爸 → 属于该行行头那个爷爷；点进格子看到的孙子 → 属于那个爸爸。
- 抽屉(行下钻/格子下钻)里链条完整。孙子本次不进总览格子（数量太多）。
