# M6 · 工作台数据落库方案（待授权）

## 一、目标
把选题工作台的规划数据从浏览器 localStorage 升级到数据库，按登录账号隔离、实时保存、永久保留。
能调的仍调现成源（GSC 收录索引 / 176 词库，不复制进库）；只把**用户规划的部分**落库：页面节点 / 词→页绑定 / 暂存 / 辅助词。

## 二、地基（已勘明）
- 这套持久化 **2026-05-29 建过(0014)、5-31 清白板时删(0015)**，设计文档完整、被删代码 git 可恢复（commit 3475b3e^）。M6 = 复活 + 扩展辅助词。
- 账号：`src/lib/auth.ts`（NextAuth），服务端 `await auth()` 取 `session.user.email` 作 owner（现单账号 `admin@weslamic.com`，多账号自动隔离，前端伪造不了）。
- DB：`src/db/client.ts` / `src/db/schema.ts`，`DATABASE_URL` 在 .env.local；migration 应用脚本模板 `scripts/_apply-00xx.ts`。
- 旧备份（备份/strategy_*_2026-05-31.json）是**废弃 demo 数据，不回灌**；新库从当前 Dhikr 规划起步。

## 三、表（复活 0014 + 1 列）
- `strategy_pages`：0014 原样（owner / page_id / role / pillar_id / title / primary_keyword / page_type / status / url / market / markets / theme_* / territory / note / sort_order / 时间戳；UNIQUE(owner,page_id)）。
  **新增 1 列**：`aux_keywords JSONB NOT NULL DEFAULT '[]'`（辅助词[实体]数组，支持可改删）。
- `strategy_bindings`：0014 原样（owner / keyword / market(空串非NULL) / page_id(NULL=暂存) / state('bound'|'parked')；UNIQUE(owner,keyword,market) 数据库层强制单词单归属）。
- migration：新写 `drizzle/0016_strategy_plan_revive.sql`（CREATE TABLE IF NOT EXISTS + aux_keywords 列），不动其余 88 表；应用脚本 `scripts/_apply-0016-*.ts` 仿 0008 模板（sql.unsafe + information_schema 验证）。

## 四、读写（复活被删代码 + 扩展）
- `_plan-store.ts`（复活）：`loadPlan(owner)` / `savePlan(owner, plan)`；kwId↔「关键词文本+市场」自然键转换（前端用 kwId，库存自然键）。扩展：plan 带 auxKeywords。
- `_plan-actions.ts`（复活，"use server"）：`saveStrategyPlanAction(plan)`，owner 由服务端 `auth()` 解析。
- 保存 = **整组覆盖**（事务内先删该 owner 全部行再插当前完整状态）→ 天然无孤儿。
- `PlanPayload`（_workbench，已存类型）扩展：pages 带 auxKeywords。

## 五、数据流 + 迁移
- 读：`strategy/page.tsx`（服务端）→ `auth()` 取 owner → `loadPlan(owner)`。有记录→DB 为准；无记录→返回 null，前端回退当前 localStorage 草稿（含已填的 Dhikr 预绑）/ 蓝图种子。
- 写：WorkbenchClient 状态变化 → 防抖 1s → server action → savePlan。DB 权威，localStorage 降级为离线兜底（并行保留）。
- 防 StrictMode 空保存：快照比对，仅变化才落库。
- **平滑迁移**：首次进页 DB 无记录 → 用当前 localStorage 的 Dhikr 规划 → 任一改动触发首次保存即落库，自此 DB 为准。无需手动导数据。

## 六、辅助词可改删（M3c 并入）
- `_data.ts` PageNode + `WbPage` + `PlanPayload` 加 `auxKeywords?: string[]`；`getWorkbenchSeed` 把现有 note 里的「辅助词[实体]：…」迁移成 auxKeywords 数组。
- InspectorPanel 辅助词区：chip 列表 + 每个可删(×) + 末尾「+ 添加」输入；改动 dispatch 新 action `SET_AUX_KEYWORDS{pageId, words}` → 入 pages 状态 → 防抖落库。
- reducer 加 `SET_AUX_KEYWORDS`（含 undo/redo 快照）。

## 七、风险 / 回滚
- 建表用 `CREATE TABLE IF NOT EXISTS`，在线 DDL 不锁现有表；先本地库验证，再决定是否上生产。
- 回滚：`DROP TABLE strategy_bindings; DROP TABLE strategy_pages;`（无损其余 88 表）。
- 整组覆盖在事务内，失败回滚不留半截。
- 前端 localStorage 兜底仍在 → 即使 DB 暂不可用也不致丢当前会话。
