# 选题工作台 · 版面重做方案

> 关联：专业方法论调研见 `选题工作台-专业方法论调研-2026-05-29.md`；数据契约见 `src/app/app/strategy/_components/_data.ts`。

## 1. 已定决策（来自与 Sean 的对齐）
- **两层**：支柱页(Pillar/hub) → 集群页(Cluster/spoke)。"领域"(产品/知识/工具/场景/品牌)只作分组标签，不嵌套成第三层。
- **它是工作台，不是展示图**：从关键词库（及其它库）筛选/捞料，**人主动绑定**成主题地图，工具在旁给专业信号。
- **嵌入真正的专业 SEO 流程**；**版面重做**。
- **单词单归属**：一个关键词只绑一个页面（这本身就是防蚕食的屏障）；歧义词进暂存篮，不强制一次定终身。
- **单人操作**（v1 不做多人协作/锁）。

## 2. 核心定位（差异化）
市面工具（Keyword Insights / Surfer / MarketMuse / Frase…）的"绑定"基本停在**自动聚类 + 表格**，不让用户手动改归属。
**本工作台的差异 = 「工具给专业信号 + 人手动绑定 + 实时校验」**——这条链市面基本空白。
→ 不做"又一个自动聚类器"；自动只负责**给建议/信号**，归属由人定。

- **① 源池**：从关键词库捞料。强筛选 + 搜索 + 虚拟滚动（扛几百词）。每词显示 量/KD/意图 chip + 绑定状态。顶部进度条"已归/未归"给到尽头感。
- **② 画布**：支柱默认折叠、点开正在编辑的。层级=支柱→集群→词。"+ 新建支柱"。三视图切换：**树**(默认,逐词绑定)/**表**(批量编辑,Excel 肌肉记忆)/**图**(只读网络总览,找 white space)。
- **③ 检视/信号**：跟随选中焦点。上=页面规格(主词/页型/目标URL/市场)，下=专业信号 + 智能建议(请示式)。
- **Dock**：暂存篮(没想好的词先扔)、冲突计数、撤销/重做、会话自动保存。

## 4. "连连看"的落地：多选 + 指派为主
- **主路径**：左侧多选一批（Shift 范围/Ctrl 加选/按筛选全选）→ "指派到…" 搜索式选择器（输入即过滤现有支柱/集群，或"新建为集群/支柱"）→ 词绑过去、源池消失、目标节点**亮一下**(连上的视觉确认=连连看快感)。
- **默认归位**：选中词时系统按 意图+语义+SERP 默认高亮"最可能归处"，回车即归、可另选（猜一下+给默认+一秒确认）。
- **拖拽**：仅作"个别词挪窝"的补充，不做主路径（几百词拖拽累手且易错）。
- **不做字面画线**：几百根线=毛球，价值在分类决策不在画线。

## 5. 嵌入的专业流程（8 步 → 映射到工作台）
1. 进料 + 意图粗筛 → ①源池筛选(先按意图分组)
2. SERP 重合度聚类（阈值默认~40%/4个URL，**可调滑块**）→ ③信号给"该合页/拆页"建议
3. 语义二次聚类成支柱 → 给"建支柱"建议
4. 人工定支柱（广、量大、与业务对齐；簇内最高量词=primary）→ ②画布"新建支柱"
5. 意图→页面类型匹配 + 冲突意图告警 → ③信号
6. 覆盖缺口检测（PAA/related/竞品子主题 → Covered/Weak/Gap + 0-100）→ ③信号(每支柱标覆盖)
7. 蚕食实时校验（绑定时查是否已有页争同词同意图）→ ③告警 + Dock 冲突计数
8. 优先级打分 `(商业相关 × 可赢度)/(KD+1)` → 机会分，画布/导出按它排执行序

## 6. 专业信号清单（视觉版：真值 vs 演示值）
| 信号 | 作用 | 视觉版来源 |
|---|---|---|
| SERP 重合度 | 该合页/拆页 | 演示值（无真实 SERP，标"示例"）|
| 意图匹配/冲突 | 页型是否对、是否混意图 | **真**（用 behavior/page_planning_intent）|
| 蚕食告警 | 多页争同词 | **真**（绑定关系内算）|
| 覆盖缺口 | 子主题覆盖度 | 演示值 |
| 机会分 | 排执行序 | **真**（量×可赢度/KD 公式）|
> 视觉/设计版：能用库里真实关键词真实绑定；需外部数据的信号(SERP/PAA)先以"示例"呈现交互，不接真实抓取。

## 7. 减负机制（产品的灵魂，非可选）
- 批量操作（多选指派/打标/打回暂存篮）
- 智能建议=请示（[接受]/[忽略]），绝不擅自归位
- 默认归位（猜+默认+一秒确认）
- 暂存篮（不强迫一次定终身）
- 撤销/重做（Ctrl+Z 必管用）
- 进度可视化 + 会话自动保存（刷新不丢）
