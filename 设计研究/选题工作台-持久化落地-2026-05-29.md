# 选题工作台 · 持久化落地

## 背景
工作台（`src/app/app/strategy`）的运营成果原先只存浏览器 localStorage（换设备/清缓存即丢、无法多账号隔离）。本次把"页面规划 + 词→页绑定 + 暂存"落库。**参考数据（关键词、GSC 排名）仍只调用现成来源，不复制进新表。**

## 已定决策
- **只新增两张表，不动任何现有表。** 迁移 `drizzle/0014_strategy_plan.sql`（手写 SQL，沿用 0000–0013 约定）。
- **按 owner（登录邮箱）行级隔离。** 注意：当前 `auth.ts` 只有单账号 `admin`（email `admin@weslamic.com`），所以"按用户各存一份"今天=一份；多账号时自动隔离。
- **绑定用「关键词文本 + 市场」自然键**（不引用静态词 id）；前端状态仍以 kwId 为键，读/写边界用 `ALL_KEYWORDS` 在 kwId ↔ 自然键之间转换。
- **保存 = 整组覆盖**：事务内先删该 owner 全部行再插当前完整状态 → 天然无孤儿数据（绕开"删页留下孤儿绑定"问题）。
- **防抖自动保存**（1s），与 localStorage 自动存并行；数据库为权威源，localStorage 降级为离线兜底。

## 表结构（详见 `src/db/schema.ts` + `drizzle/0014_strategy_plan.sql`）
- `strategy_pages`：`id` bigserial PK · `owner` · `page_id`(工作台内部 id) · role/pillar_id/title/primary_keyword/page_type/status/url/market/markets(jsonb)/theme_*/territory/note/sort_order/时间戳。UNIQUE(`owner`,`page_id`)，INDEX(`owner`)。
- `strategy_bindings`：`id` bigserial PK · `owner` · `keyword` · `market`(无市场用空串 `''`，非 NULL) · `page_id`(NULL=暂存篮) · `state`('bound'|'parked') · 时间戳。UNIQUE(`owner`,`keyword`,`market`)（数据库层强制"单词单归属"），INDEX(`owner`)、(`owner`,`page_id`)。
- `page_id` 不建外键，应用层"整组覆盖"保证一致性。

## 数据流
- **读**：`strategy/page.tsx`（服务端组件）→ `auth()` 取 owner → `loadPlan(owner)`。有记录→返回；无记录→返回 null，前端回退 localStorage 草稿/蓝图种子。
- **写**：`WorkbenchClient` 状态变化 → 防抖 1s → Server Action `saveStrategyPlanAction(plan)`（`_plan-actions.ts`，owner 由服务端会话解析，前端无法伪造）→ `savePlan(owner, plan)`。
- **防 StrictMode 空保存**：用序列化快照比对，仅在快照与上次不同才落库（mount/重挂的快照==初始值→不触发）。

## 关键文件
- `src/db/schema.ts`（+ strategyPages / strategyBindings）
- `drizzle/0014_strategy_plan.sql`（建表迁移）
- `src/app/app/strategy/_components/_plan-store.ts`（loadPlan / savePlan + kwId↔自然键转换）
- `src/app/app/strategy/_components/_plan-actions.ts`（"use server" 保存 action）
- `src/app/app/strategy/page.tsx`（按 owner 读取 initialPlan）
- `WorkbenchWrapper.tsx` / `WorkbenchClient.tsx`（透传 initialPlan + 初始化优先级 DB>本地>种子 + 防抖落库）
- `_workbench.ts`（`PlanPayload` 共用类型）
